OPEN & PREVIEW
1. Extract this ZIP completely (do not open index.html inside the ZIP).

4. Scroll or use browser Find. Tap each 18th Tradition to open all names.

RSVP — SAME BROWSER TAB
The RSVP button now opens your EXISTING Google Apps Script app in the SAME browser tab (target _self), not a separate tab. Your previously working Google Sheets integration is not changed by this website. Use your browser Back button to return to the invitation. Embedding the RSVP directly inside the invitation page would need updating and redeploying the Apps Script to allow framing, which can expose the application to additional framing risks; we have not done that.
